# Баг репорт - Para Bank

## Обзор
Этот документ содержит **баг репорты**, демонстрирующие правильный формат и структуру документации по ошибкам. Эти примеры демонстрируют проффесиональные навыки составления отчетов об ошибках.

---

## 🐛 BUG ID #001: Регистрация: некорректная ошибка при вводе в поле более 30 символов

**Статус:** Пример
**Серьезность:** Major
**Приоритет:** Hight
**Найден:** Папанова Кристина
**Дата:** Август 2026

### Окружение
- **Приложение:** Para Bank
- **URL:** https://parabank.parasoft.com/parabank/index.htm
- **Браузер:** Яндекс Браузер 26.6.5.631 (64-bit)
- **ОС:** Windows 11 Pro 25H2
- **Разрешение экрана:** 1920x1080

### Описание
- При пересечении максимального граничного значения, вместо ошибки об ограничении допустимой длины, отображается ошибка у поля username "This username already exists"

### Шаги воспроизведения
1. Заполнить обязательные поля
2. В поле Last Name ввести строку из 30+ символов
3. Нажать Register

### Ожидаемый результат
- Поле ограничивает ввод количеством 30 символов.

### Фактический результат
- Страница перезагружается и выводит некорректую ошибку у поля username "This username already exists"

## 🐛 BUG ID #003: Перевод между счетами: перевод суммы, превышающей баланс

**Статус:** Пример
**Серьезность:** Critical
**Приоритет:** Hight
**Найден:** Папанова Кристина
**Дата:** Август 2026

### Окружение
- **Приложение:** Para Bank
- **URL:** https://parabank.parasoft.com/parabank/index.htm
- **Браузер:** Яндекс Браузер 26.6.5.631 (64-bit)
- **ОС:** Windows 11 Pro 25H2
- **Разрешение экрана:** 1920x1080

### Описание
- При попытке перевести сумму свыше актуального баланса, перевод не блокируется, исполняется. Баланс отправителя уходит в минус

### Фактический результат
- Перевод успешно выполнен. Баланс отправителя уходит в минус
