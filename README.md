# Примеры ручного тестирования – демо-банк Para Bank

Этот репозиторий содержит практические примеры документации по ручному тестированию демонстрационного интернет-банка Para Bank (https://parabank.parasoft.com/parabank/index.htm).
В нем демонстрируется комплексный подход к разработке и выполнению тестовых сценариев, а также к составлению отчетов об ошибках для реального приложения.
---

## 📝 Обзор проекта

**Цель:**  
Проверить основные функции демо-банка Para Bank с помощью структурированного ручного тестирования, включая регистрацию, вход в систему, перевод между счетами, открытия нового счета и оплату счетов.

**Тестируемое приложение:**  
Para Bank - https://parabank.parasoft.com/parabank/index.htm
Демонстрационная платформа для обучения и тестирования.

**Область применения:**  
- ✅ Регистрация и аутентификация пользователей
- ✅ Вход и выход из аккаунта
- ✅ Открытие новых saving и checking счетов
- ✅ Перевод между активными счетами 
- ✅ Оплата счетов по актуальным данным

## ⚙️ Подход к тестированию

### Стратегия тестирования
- **Тип:** Ручное функциональное тестирование
- **Методология:** Тестирование "черного ящика"
- **Уровни тестирования:** Системное тестирование, приемочное тестирование
- **Техники тестирования:** 
  - Эквивалентное разбиение
  - Анализ граничных значений
  - Угадывание ошибок

### Среда тестирования
- **URL:** https://parabank.parasoft.com/parabank/index.htm
- **Браузер:** Яндекс Браузер 26.6.5.631 (64-bit)
- **ОС:** Windows 11 Pro 25H2
- **Разрешение экрана:** 1920x1080
- **Период выполнения тестов:** Август 2026
